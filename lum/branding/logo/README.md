# Lum logo

Mark: a crescent moon with a star, soft shading, no outlines.

| File | Use |
|---|---|
| `lum-mark.svg` | Main mark, transparent background, for dark backgrounds |
| `lum-mark-light-bg.svg` | The same mark in navy, for light backgrounds |
| `lum-mark-round.svg` | Round badge (navy circle), app icon |
| `lum-mark-round-inverted.svg` | Round badge in inverted colors (cream circle, navy moon) |
| `lum-favicon.svg` | Simplified round version without shadows, for the favicon and small sizes |
| `lum-favicon-inverted.svg` | Favicon in inverted colors |
| `preview.html` | Preview of all files, open it in a browser |

Colors: navy `#0F1222`, cream `#F4F1EA`, star gold `#FFD66B`.
